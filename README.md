# ✦ InteDesign Studio

A full-stack modern web application for an interior design studio, featuring an **AI-powered Style Explorer**, a **Pinterest-style Vision Board**, and an extensive **Admin Dashboard** for managing content and leads.

![InteDesign Preview](client/public/favicon.svg)

## 🎨 Design System: NeoPop
This project utilizes a customized **NeoPop** aesthetic:
- **High Contrast**: Pure white backgrounds (`#FFFFFF`) with heavy black borders (`#000000`).
- **Vibrant Accents**: Striking pops of color like Yellow (`#FFCE00`) and Pink (`#F472B6`).
- **Typography**: Bold, brutalist, uppercase typography (`Inter` / `Outfit`).
- **Micro-interactions**: Hard shadows (`4px 4px 0px #000000`) that flatten on hover to simulate physical buttons.

## ✨ Key Features

### 1. AI Style Explorer
- Users describe their dream room, select a budget and timeline.
- The backend communicates with **Google Gemini AI** to generate a highly detailed prompt.
- **Unsplash API** is used to fetch corresponding high-quality real-world images matching the style.

### 2. My Vision Board
- Users can save their favorite images from the Portfolio or AI Explorer.
- Displayed in a highly responsive **Masonry Grid** layout.
- Authenticated users can view their past saved boards via the **History** modal.
- Includes a 1-click **Download PDF** feature using `jsPDF`, which generates a beautiful, branded, multi-page Vision Board document to share with the design team.

### 3. Admin Dashboard
- Secure JWT-protected portal.
- **Leads Management**: View and process form submissions.
- **Portfolio Management**: Full CRUD for projects and services.
- **Vision Board Analytics**: Admins can see the boards generated by users.
- **Legal Docs CMS**: Edit Privacy Policy and Terms of Service directly from the UI.

### 4. Smart Server Wake-up (Render Support)
- Built specifically for free-tier deployments on **Render**.
- The Login page features a **60-second reverse timer** that pings the backend `health` route. It disables the login form until the server responds, ensuring users don't encounter timeouts during cold starts.

## 🛠 Tech Stack

**Frontend (Client):**
- React 18 (Vite)
- Tailwind CSS
- Framer Motion (Page transitions & micro-animations)
- React Router DOM
- jsPDF (Client-side PDF generation)
- React Masonry CSS

**Backend (Server):**
- Node.js & Express
- MongoDB (Mongoose)
- JSON Web Tokens (JWT) & bcryptjs
- Axios (For external APIs like Gemini & Unsplash)
- Sharp (Image proxying & processing)

## 🚀 Deployment Instructions

### Frontend (Vercel)
1. Import the repository into **Vercel**.
2. Set the Root Directory to `client`.
3. Framework Preset: **Vite**.
4. Build Command: `npm run build`
5. Environment Variables:
   - `VITE_API_BASE_URL` = `https://your-backend-url.onrender.com`

### Backend (Render)
1. Create a new Web Service on **Render**.
2. Set the Root Directory to `server`.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Environment Variables:
   - `PORT` = `5000`
   - `MONGODB_URI` = `your_mongo_connection_string`
   - `JWT_SECRET` = `a_secure_random_string`
   - `ADMIN_EMAIL` = `admin@intedesign.studio`
   - `ADMIN_PASSWORD` = `your_admin_password`
   - `GEMINI_API_KEY` = `your_google_gemini_key`
   - `UNSPLASH_ACCESS_KEY` = `your_unsplash_key`

## 💻 Local Development

1. **Clone the repo**
   ```bash
   git clone https://github.com/1anmol1/InteDesign.git
   cd InteDesign
   ```

2. **Setup Environment Variables**
   - In `server/.env`, provide your MongoDB URI and API keys.

3. **Start the Backend**
   ```bash
   cd server
   npm install
   npm run dev
   ```

4. **Start the Frontend**
   ```bash
   cd client
   npm install
   npm run dev
   ```
